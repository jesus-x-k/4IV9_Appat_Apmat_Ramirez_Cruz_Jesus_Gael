Nombre: Ramírez Cruz Jesús Gael

Institución: CECyT 9 "Juan de Dios Bátiz"

Materia: Programación Intermedia

Objetivo del Portafolio

Documentar el desarrollo académico y técnico de las prácticas realizadas durante el semestre, demostrando la aplicación de los conocimientos adquiridos en el aula sobre el lenguaje Java y la conectividad con bases de datos.

Aprendizajes Clave

  • Fundamentos y POO: Implementación de clases, herencia y estructuras de control.
  • Estructuras de Datos: Gestión de información dinámica mediante el uso de Arreglos y ArrayList.
  • Manejo de Datos: Aplicación de serialización y desarrollo de sistemas CRUD (Crear, Leer, Actualizar, Borrar) conectados a SQL.
  • Interfaces Gráficas: Desarrollo de ventanas funcionales para la interacción del usuario final.
